# 寰游 · ATLAS OF EARTH

以三维地球为入口的全球地理与文明图鉴。旋转地球，在六大洲的自然奇境与文明地标之间探索，通过真实地形、卫星影像、实景建筑与图文手记认识世界。原有中国地理内容完整保留。

产品聚焦 PC 浏览器，地图占据主要空间；本轮性能与清晰度优化只验证 PC。首页精选地点默认收起，按大洲与国家定位，按自然、文明或主题旅程继续探索。全球内容与模型来源详见 [WORLD_ATLAS.md](WORLD_ATLAS.md)。

目前收录 **86 个国家、199 个地点、30 条主题旅程**，其中国外 118 处地点配有 236 幅不同的真实摄影。三维建筑开放 **16 个片区**：香港六处、赫尔辛基六处、里昂一处、墨尔本三处。本轮新增 61 个地点、122 幅摄影、7 条旅程和 7 个实景片区。其余地标以卫星影像与图文介绍呈现。

独立公开版：[打开寰游](https://mastiusbkbk-max.github.io/huanyou-earth-atlas/)。源码分支为 `codex/pc-performance-pages`，完整高清模型通过独立资产站发布；历史模型保存在本仓库 Release，未覆盖原来的 `china-atlas` 网站。容量、恢复方式与自动发布参数见 [GITHUB_PAGES.md](GITHUB_PAGES.md)。

## 运行

需要 Node.js 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。正式构建与预览：

```bash
npm test
npm run build
npm run serve
```

`dist/` 是完整静态网站，可部署到支持 HTTPS 的静态托管平台；不需要数据库、后端服务或 API Key。构建会生成 Brotli/gzip 预压缩文件与缓存校验清单，`npm run serve`（默认 4173）与 `npm run preview` 均支持这些文件。其他托管平台需配置相同的内容协商、缓存与 `Vary` 响应头才能获得相同交付效果。默认构建使用 GitHub Pages 的 `/china-atlas/` 子路径。若部署到域名根目录，使用 `npm run build -- --base /` 重新构建。不能直接双击 HTML 运行，需要 HTTP 服务。

## 探索方式

- 拖动平移，滚轮缩放，右键拖动旋转和倾斜。
- 点击地图标记或照片卡片，镜头飞向真实地点，展开地理与人文介绍。
- 地点详情以图文手记呈现：封面、事实卡、两段专属章节、第二幅地点影像及“在这里，看见什么”观察手记。点击图片查看大图，支持左右按钮、方向键切换，`Esc` 关闭后回到原阅读位置。
- 地点介绍在左侧独立滚动，查看大图时自动暂停漫游，切换地点重置阅读位置。
- 顶部大洲与国家组合筛选，底部展开精选或打开全球目录；自然 / 文明筛选，支持中文、英文、国家、区域与标签搜索；`⌘/Ctrl + K` 或 `/` 打开搜索。
- 图层面板切换卫星影像与地形晕渲，叠加省级边界；山系与水系默认开启，可分别隐藏。
- 暖金虚线呈现山系总体走向，冷青线呈现主要水系，黄河以金色区分。全国视野先显示主干，区域放大后逐步显示支流与更多山系。
- 点击山脉、河流的线条或中文名称，高亮选中对象、适配其视野，并展开地理介绍、所属水系或总体走向、来源与精度说明。图层面板可按名称定位全部 **84 项**山系和河流。
- `3D` 切换三维 / 平面，指南针恢复正北，房屋按钮回到地球全景。
- 环游世界每 11 秒前往下一处，支持暂停、继续与跳转；全球主题与中国专题组织不同的地理叙事；首页提供全球精选 12 站漫游，约 2 分钟。
- 地点链接支持 `/#everest` 等直接访问。`Esc` 关闭对话框或返回全景。
- 点击右上角“实景地标”，切换已接入的国外地标或原有香港六片区。每个片区分别展示来源、拍摄年份或修订日期与覆盖范围。支持旋转、缩放和“回到片区”，金色虚线标示当前模型范围。“卫星影像”返回普通地图，切换片区、离开范围或选择其他地点会释放旧模型。

模型范围、官方许可、原始坐标与高程基准、处理方式和复现步骤见 [WORLD_SCENE_DATA.md](WORLD_SCENE_DATA.md) 与 [LANDMARK_SCENE_DATA.md](LANDMARK_SCENE_DATA.md)。仅已核验片区提供模型入口；埃菲尔铁塔、悉尼歌剧院等已收录地标尚未接入建筑模型，详情中有明确说明。

## 内容与资料

中国部分保留 **81 个代表坐标**，覆盖 **34 个省级行政区**，包含五岳与名山、雪山高原、江河峡谷、湖泊湿地、沙漠海岸，以及古城、宫殿、石窟、园林与文化景观。新增内容如泰山、华山、黄河壶口、雅鲁藏布大峡谷、九寨沟、长白山、巴丹吉林、太鲁阁、兵马俑、布达拉宫、莫高窟、龙门石窟、苏州园林、福建土楼和红河哈尼梯田。

**全球目录**提供八类主题、已收录国家和关键词的组合筛选；地图标记随缩放和空间避让逐步呈现，选中地点始终保留。目录和搜索可找到所有地点。

**既有中国 12 条主题旅程**：三级阶梯、五岳名山、雪山高原、江河峡谷、湖泊湿地、沙漠红层、山林生态、海岸岛屿、古都中轴、石窟与造像、古城都市、园林乡土。每处地点至少纳入一条路线，专题卡片显示站数与预计时间。

**24 条山系与 60 条河流 / 河段**构成地图的地理骨架。山系包含喜马拉雅、昆仑、天山、秦岭、太行等；水系包含长江、黄河、黑龙江、松花江、辽河、海河、淮河、珠江、闽江、澜沧江、怒江、雅鲁藏布江与塔里木河等代表性水系。长江、金沙江、通天河、沱沱河及珠江水系的西江、浔江、黔江、红水河、南盘江保留各自河段名称。图层适用于全国与区域认知，三维和平面模式都可探索；放大至 zoom 7.3–8.5 时线条与标签逐渐隐去，转而观察影像与真实地形。

内容位于 `src/content.js`、`src/content-nature.js` 与 `src/content-culture.js`；路线与分类见 `src/journeys.js`。摄影均为真实地点的 Wikimedia Commons 作品；作者、原作、公开许可或公有领域说明与图片缩放压缩说明保存在 `public/data/photo-sources.json`，站内说明及地点详情提供来源和许可链接。字体为 OFL 授权的本地 Noto Serif SC 中文子集，避免依赖在线字体。

`src/place-stories.js` 为全部 81 个地点提供 162 个专属章节标题及逐处观察手记，连接地理成因、自然生态与人文空间。每处新增一幅不同于封面的地点影像，共 81 幅、约 14.25 MB；最长边不超过 1200 像素，随详情按需加载。来源清单为 `public/data/detail-photos-nature.json` 与 `public/data/detail-photos-culture.json`，每幅均附中文图注、替代文本、作者、许可与原作链接，可在图注下展开或在“关于寰游”集中查阅。莫高窟采用一幅壁画忠实复制图，贺兰山及大足的补图为展陈照片，均在图注明确说明；不将复制图或展陈冒充现场景观。

## 地图精度与网络

- MapLibre GL JS 6.15 渲染球形地球，并在 zoom 5–7 过渡为 Mercator 地表视图；建筑实景使用 Mercator 精确叠加，退出后恢复地球投影。影像来自 Esri World Imagery / World Shaded Relief，高程来自 Mapzen / AWS Terrain Tiles。
- 三维起伏为真实高程栅格驱动；普通山岳垂直起伏放大 **1.5 倍** 以便观察。太平山实景背景使用 **1 倍** DEM，里昂采用同版官方地面 TIN 生成的 **1 倍**局部地形，其余现有实景采用平面背景。海外模型在渲染时将椭球高与地形使用的高程基准对齐，原始模型文件保持不变。卫星影像拍摄时间、分辨率及 DEM 精度因地区而异。
- 上海外滩的城市高程存在局部伪起伏，因此采用平面地表的城市卫星影像，镜头倾角为 30°；该地点停用 DEM 与晕渲，按钮标示 2D。离开外滩恢复用户原有的三维偏好，不影响山岳地点。卫星影像不包含三维建筑模型。
- DataV GeoAtlas 原始全国轮廓和省级边界包含 34 个省级行政区，保留台港澳、海南及南海原始几何。边界为概略地理数据，近景自动隐去，不作为测绘、法律或导航依据。
- 叙事地点采用 WGS84 代表位置，并不等同于照片拍摄机位、景区入口或景区范围。桂林点位依据照片公开 GPS；珠峰使用峰顶位置；金山岭与月牙泉已与照片主题校正。
- 珠峰 **8848.86 米** 是 2020 年共同公布的雪面高程，独立于栅格 DEM 采样结果。青海湖湖面海拔用约数，并说明随水位变化。
- 水系来自 [Natural Earth 1:1000万河流与湖泊中心线](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-rivers-lake-centerlines/)，依据其[公有领域条款](https://www.naturalearthdata.com/about/terms-of-use/)使用。60 项为代表性选择，并非完整中国河网；保留源数据原始顶点与分段，不补绘湖区、河口或断段，也不据此推算实测河长。部分跨境河流保留境外延续；岷江、沱沱河、塔里木河等存在未收录河段，长江下游与部分河口也未完整表示，逐条说明见 `public/data/rivers.geojson`。中心线不代表精确河岸、当前河道或航道。
- 山系来自公开地理资料核对后的**手工概化走向轴线**，未从 DEM 提取山脊，也未采集 GPS 轨迹；暖金虚线不代表精确山脊、山系边界或登山路线。24 项的逐条资料链接、方向与精度说明见 `public/data/mountains.geojson`；参考资料用于核对山系名称和区域背景，并非轴线节点坐标来源。
- 山系与水系的三级层级仅用于控制展示密度，不是官方山系等级或水文河流级序。世界遗产条目链接及政府机构链接可供进一步查阅，部分机构主页不是逐条论断的原文出处。
- 基础缓存覆盖全球 z0–4、亚洲范围（55°E–180°E，20°S–70°N）z5 的三类瓦片，共 **1,419 张、约 42.79 MB**，另补充 **5,468 张**中国地点与香港实景周边瓦片，以及独立清单管理的 **4,731 张**世界目的地、国外实景与国家入口稀疏瓦片（部分复用既有文件）。首屏、字体、摄影、边界和内容可由本地服务器直接提供；未缓存的近景仍需连接在线瓦片服务，范围见下方加载性能说明。
- 需要支持 WebGL 的现代浏览器。正式公开部署前，应根据实际托管环境检查外部瓦片连通性和相应服务使用条款。

地图来源与缓存范围：`public/data/map-sources.json`。重新获取瓦片可运行 `node scripts/cache-map.mjs`；该脚本使用 `curl`，并保留已存在的缓存。

重建水系可运行 `python3 scripts/build-rivers.py`，或使用 `--source /path/to/ne_10m_rivers_lake_centerlines.geojson` 指定已下载的原始数据。生成结果保留源要素编号、选用组件和原始文件 SHA256，便于追溯；脚本只使用 Python 标准库。上游数据更新后，应重新核对名称、汇流点和显示范围。

## 验证

`npm test` 检查地理与图文资料、瓦片协议、缓存文件和字节一致性、城市/山地视图偏好及实景渲染生命周期。每个已接入实景片区分别验证全部模型与内嵌摄影纹理、SHA256、加载索引闭合、原始坐标变换、实际范围、日期和版权；数据测试不能替代浏览器中的实际渲染检查。

浏览器验证记录按轮次保存在 `VALIDATION.md`；既有记录保留各轮实际检查范围，本轮结果以新增记录为准。数据测试不替代浏览器中的三维渲染、交互和视觉检查。本项目为独立科普与设计作品，与星球研究所无关联。

## 加载性能

地图先显示全球卫星影像并开放探索，近景再补充真实三维地形、区域山河名称及图文资料。世界内容和中国内容分开维护，由 `src/atlas-content.js` 聚合；世界内容为 `src/content-world.js`，实景配置为 `src/world-scenes.js`。地图引擎与 Worker 提前启动；地点标记使用地图原生符号图层完成投影、遮挡与碰撞，省界、山河资料、摄影元数据与收起的照片卡片按需加载。

卡片使用 480px WebP 缩略图，详情与大图使用较高分辨率版本；本地高程使用逐像素 RGB 验证一致的无损 WebP。重建缩略图和原有低倍地形缓存可运行 `python3 scripts/optimize-assets.py`，需要 Pillow。

`node scripts/cache-world.mjs` 为世界景点、已接入国外实景与国家入口补充稀疏缓存，另用 `public/data/tiles-world.json` 管理，保持中国既有缓存文件不变。全球低倍可由本机提供，未缓存的高倍、倾斜视野或平移仍需联网。

`node scripts/cache-destinations.mjs` 补充 81 个地点附近、精选地点及部分飞行中间级别的稀疏缓存，成功条目和来源记录在 `public/data/tiles-detail.json`。它不是完整离线地图，未缓存的倾斜视野、平移区域和缩放级别继续访问原始服务。脚本可重入，下载总量限制为 200 MB。

瓦片请求合并，并隔离多个图层的取消操作；内存缓存上限 32 MiB。支持 Cache Storage 的浏览器会在后台保存已成功浏览的在线瓦片，上限 64 MiB / 400 张；缓存不可用时正常回源。本轮 PC 原档优化、指标定义与实测见 [PERFORMANCE_PC.md](PERFORMANCE_PC.md)，历史记录见 [PERFORMANCE.md](PERFORMANCE.md)。
